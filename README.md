# 💈 Barber Nail · Marlon & Carol  
### Estudio de barbería y manicura premium en Palencia


✨ **WEB:** [https://barbermarlonnailcarol.netlify.app/](https://barbermarlonnailcarol.netlify.app/)


## 🧾 Descripción
Este repositorio contiene el código fuente completo de la **página web comercial** para el negocio **Barber Marlon Nail Carol**, un estudio mixto de **barbería** y **diseño de uñas**, ubicado en **Palencia, España**.

El sitio está diseñado para:
- Mostrar los servicios y el trabajo realizado.
- Facilitar el contacto directo por teléfono e Instagram.
- Funcionar perfectamente en móviles, tablets y ordenadores.
- Ofrecer una experiencia visual atractiva y profesional.

---

## 🚀 Tecnologías utilizadas

- **HTML5**
- **Tailwind CSS** 
- **CSS personalizado** 
- **JavaScript vanilla**
- **Font Awesome 6** 
- **Google Fonts (Inter)**
